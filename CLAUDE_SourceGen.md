# Source Generator Implementation Plan

## Context

The project uses Unity Localization with string tables (SharedData + StringTable asset pairs). A Roslyn source generator in `SourceGenerators/Unity.Localization.Roslyn/` generates type-safe accessor methods. The goal: replace scattered `GetLocalizedString()` calls with compile-time-safe `Loc.TableName.MethodName(args)` calls.

The existing `Loc.cs` in `Assets/Features/Localization/` has `Get()` helpers. The source generator produces the other half of this `partial class Loc` — namespace `Features.Localization`, class `Loc`.

## How Smart Strings Work at Runtime

From actual codebase usage (e.g., `LevelInfoBox.cs:60`):
```csharp
levelIndexString.GetLocalizedString(new { _int_LevelIndex = levelInfo.DisplayIndex });
```
SmartFormat resolves `{_int_LevelIndex}` via reflection on the anonymous object. The existing `Loc.Get(table, id, params object[] args)` works for both positional and smart strings — for smart strings, pass a single anonymous object as the argument.

## Generated Output Example (SourceGenTest table)

```csharp
// <auto-generated/>
namespace Features.Localization
{
    public static partial class Loc
    {
        public static class SourceGenTest
        {
            private const string Table = "SourceGenTest";

            /// <summary>nothing special. no placeholders.</summary>
            public static string Normal() => Get(Table, 18042413056);

            /// <summary>{0} position {1} args</summary>
            public static string PositionalArgs(object arg0, object arg1)
                => Get(Table, 144353878016, arg0, arg1);

            /// <summary>Smart. Int arg {_int_Argument}</summary>
            public static string SmartStringSingleInt(int Argument)
                => Get(Table, 313619210240, new { _int_Argument = Argument });

            /// <summary>int: {_int_Arg1}, string: {_string_Arg2}, default: {Arg3}, default2:{Arg4}</summary>
            public static string SmartStringMultipleMixed(int Arg1, string Arg2, string Arg3, string Arg4)
                => Get(Table, 1007768133632, new { _int_Arg1 = Arg1, _string_Arg2 = Arg2, Arg3, Arg4 });
        }
    }
}
```

## Method Naming Rule

1. If key starts with `{TableCollectionName}.`, strip that prefix
2. Remove remaining dots to concatenate segments -> method name
3. Example: key `SourceGenTest.SmartString.Multiple.Mixed` -> method `SmartStringMultipleMixed()`
4. Keys without table prefix (e.g., `SmartString.Simple.WithoutTableNameInKey`) -> `SmartStringSimpleWithoutTableNameInKey()`

## Argument Classification

- **No args**: entry has no placeholders -> `Get(Table, id)`
- **Positional args** (`{0}`, `{1}`): entry is NOT a smart string -> `Get(Table, id, arg0, arg1)`
- **Smart args** (`{_int_Name}`, `{Name}`): entry IS a smart string (listed in `SmartFormatTag.m_SharedEntries`) -> `Get(Table, id, new { _int_Name = Name, ... })`
- **Smart string with no placeholders**: just `Get(Table, id)`

Type prefix convention: `_int_` -> `int`, `_string_` -> `string`, `_float_` -> `float`, `_double_` -> `double`, `_bool_` -> `bool`, `_long_` -> `long`, no prefix -> `string`

## Pairing Logic

1. SharedData files contain `m_TableCollectionNameGuidString: <GUID>`
2. StringTable files contain `m_SharedData: {fileID: 11400000, guid: <GUID>, type: 2}`
3. Match by GUID. The table collection name comes from SharedData's `m_TableCollectionName`.

## Smart String Detection

In `_en.asset`, the `references.RefIds` section has entries like:
```yaml
- rid: 1739500476379431004
  type: {class: SmartFormatTag, ...}
  data:
    m_SharedEntries:
    - id: 223106129920
    - id: 313619210240
```
Entries listed under `m_SharedEntries` (and `m_Entries`) are smart strings.

## Files

1. `SourceGenerators/Unity.Localization.Roslyn/SharedTableData.cs` — record with Guid, TableCollectionName, Entries
2. `SourceGenerators/Unity.Localization.Roslyn/TableInfo.cs` — holds table name, collection name, and parsed EntryInfo[]
3. `SourceGenerators/Unity.Localization.Roslyn/LocalizationAssetParser.cs` — YAML parsing logic
4. `SourceGenerators/Unity.Localization.Roslyn/SourceGenerator.cs` — pairs files, parses, generates `partial class Loc`
5. `SourceGenerators/Unity.Localization.Roslyn/EntryInfo.cs` — record for a single entry (Id, Key, EnglishText, Args)
6. `SourceGenerators/Unity.Localization.Roslyn/EntryArg.cs` — record for an argument (Name, Type, Formatter)
