# Localization: Campsite
Strings used in the Campsite page. All strings will be found in the main page or in any of the 3 tent-pages.

## Key Organization
There are 3 pages and the main Campsite menu.
- Campsite.Storage.*: Storage Tent
- Campsite.Carts.*: Cart & Upgrades Tent
- Campsite.Retinue.*: Companions Tent
