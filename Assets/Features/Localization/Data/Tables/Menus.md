# Localization: Menus
This collection of strings contains texts from most menus in the game, including on-screen panels like the caravan or player UI panels. Most keys are either self-explanatory or described in the table itself.

## Key Orgnization
- Menus.Start.*: Strings in the start page/level selection screen
- Menus.PlayerPanel.*: Strings in the UI at the center-top of the screen, around the player icon, Play/Pause buttons, etc.
- Menus.GameOver.*: Strings in the end-of-game ui, after the player won/lost a level. See the cheat section below to test.
- Menus.Feedvack.*: Strings int the feedback form, accessed through the Escape-Menu or the button in the level selection screen.
- Menus.Caravan.*: Strings in the caravan panel in the top left of the screen, unfolded by clicking the UI element with the horse header or by pressing [Q].
- Menus.Credits.*: Strings in the credits page, accessed through the Escape-Menu or the button in the level selection screen.
- Menus.Escape.*: Strings in the Escape menu.
- Menus.Settings.Audio.*: Strings in the audio settings, accessed through the escape menu.

## Cheats to win/lose a level
The [F9]-key opens the cheat console.
Just type cheats into the textfield that pops up at the top of your screen. All cheats are without the " symbols.
- "town.upgrade.all" will upgrade all towns to tier 3
- "funds X" will give you X amount of money, so for example type "funds 99999" for 99.999 cash
- "funds -X" will remove X amount of your money, so for example "funds -5000" will remove 5k cash. If you then wait for 7-14 ingame days, you will lose due to bankcruptcy.
- "town.reputation.all" will set all towns' reputations to 100
